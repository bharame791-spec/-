# ما زلتُ أختاركِ: تصميم الرواية

- `manuscript.txt`: نص الرواية. أي تعديل على النص بيصير هون.
- `illustrate.py`: بيرسم كل رسومات الكتاب بالكود (الغلاف، ومشهد لكل فصل، والخاتمة، وورق الصفحات). الرسومات أصلية ومحفوظة بمجلد `art/`.
- `build.py`: بيركّب الكتاب كامل من النص والرسومات (بيحتاج Python مع Pillow و numpy و pypdf، و Node مع Playwright، و poppler-utils).
- `output/`: الملفات الجاهزة:
  - `ma-zilt-akhtaruki-screen.pdf`: الرواية كاملة مع الغلاف، للقراءة والمشاركة.
  - `ma-zilt-akhtaruki-print-interior.pdf`: داخل الكتاب للمطبعة، قياس A5، وكل فصل بيبلش على صفحة يسار.
  - `ma-zilt-akhtaruki-cover.pdf`: الغلاف الأمامي والخلفي.

لإعادة البناء بعد أي تعديل: `python3 build.py` (وإذا تعدّلت الرسومات: `python3 illustrate.py` قبلها).

الخطوط: أميري (النص)، عارف رقعة (العناوين)، جلزار ولاله‌زار (عنوان الغلاف)، ريم كوفي، وكورموران. كلها مرخّصة برخصة SIL Open Font License.
