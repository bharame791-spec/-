# محمد الضيف | رجل الظل: موشن جرافيك (كولاج)

فيديو عمودي 1080×1920، مدته 78 ثانية، 25 إطارًا في الثانية، مع الفويس أوفر (`sources/voiceover.mp3`) وموسيقى ومؤثرات صوتية.

- `output/audio_stems/`: الموسيقى والمؤثرات كملفين منفصلين، لو حبيت تعيد المكساج في برنامج المونتاج
- توقيت كل لقطة مأخوذ من توقيت الكلمات في الصوت (`sources/voiceover_words.json`)

- `output/deif_shadow_man_1080x1920.mp4`: النسخة النهائية
- `output/deif_shadow_man_preview_720p.mp4`: نسخة خفيفة للمعاينة

## المشاهد وتوقيتها مع الصوت
| المشهد | الوقت |
|---|---|
| 1. الاسم بلا وجه (5 لقطات) | 0:00 – 0:08 |
| 2. البدايات | 0:08 – 0:26 |
| 3. من الظل | 0:26 – 0:45 |
| 4. المطاردة | 0:45 – 0:54 |
| 5. الإعلان | 0:54 – 1:05 |
| 6. رحل كما عاش | 1:05 – 1:16 |

الفيديو مقسوم إلى 34 لقطة، لقطة لكل جملة من الفويس أوفر، وبين كل لقطتين حركة كاميرا (سحب سريع مع موشن بلير، أو دخول بالتقريب، أو تلاشٍ). بداية كل لقطة موجودة في المصفوفة `C` داخل `scene/main.js`. إذا كانت لقطة تسبق جملتها في الصوت أو تتأخر عنها، عدّل الرقم المقابل وأعد الرندر.

## إعادة البناء
```bash
tools/extract_clips.sh <فيديو الجزيرة الوثائقي> build/clips   # اللقطات الأرشيفية
python3 tools/make_textures.py .                                 # الورق والحبيبات والهافتون
node render.mjs --stills 5,20,40                                  # صور سريعة للمعاينة
node render.mjs                                                   # الفيديو الكامل -> build/
```
