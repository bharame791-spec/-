# شعار رام متحرك — "قريباً"

تحريك لشعار **رام للشؤون العسكرية والأمنية** بأسلوب **Trim Path** (طبقة طبقة)، مستوحى من فيديو شعار الجزيرة:

كل طبقة تنرسم أولاً كـ**ستروك** (خط الحواف) ثم يلحقها الـ**فيل** بعد جزء من الثانية، والطبقات متتابعة بسرعة مع تداخل بسيط (الشعار يكتمل خلال ~1.6 ثانية):

1. الشريط العلوي.
2. الشريط الثاني ← الحلقة ← رأس السهم ← الهلال الخارجي (مسار واحد متصل).
3. الهلال الرمادي الداخلي.
4. لمعة ضوء تمرّ على الشعار، الخط الفاصل ينمو و"RAM" و"رام" ينزلقان من خلفه، ثم السطر الفرعي.
5. كلمة **"قريباً"** تظهر من اليمين لليسار مع لمعة.

كل طبقة مفصولة من الشعار الأصلي نفسه (باللون والاتصال)، والكشف يتبع المسافة على طول الطبقة من طرفها، لذلك الحافة دائماً تقطع الشريط بالعرض مثل Trim Path في After Effects. الإطار النهائي مطابق للشعار الأصلي.

الصوت مُصمَّم برمجياً بالكامل: Whoosh لكل طبقة مع Pan يتبع اتجاه الرسم، Riser، Impact مع رنين، Tick عند الفاصل، Swish ستيريو للأسماء، Chime لكلمة "قريباً"، وReverb.

- الفيديو: `out/coming_soon.mp4` (‏1080×1920، 30fps، 7 ثوانٍ، AAC ستيريو 48kHz، ‎-14 LUFS)
- السكربت: `src/render.py` — التوقيتات (`T_LAYERS`, `FILL_LAG`, `T_HIT`, `T_SOON0`…) في أعلاه.

```bash
pip install numpy pillow scipy   # ffmpeg مطلوب أيضاً
python3 src/render.py            # -> out/coming_soon.mp4
python3 src/render.py --preview  # صور معاينة كل نصف ثانية
```
