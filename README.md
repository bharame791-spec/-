# شعار متحرك — "قريباً"

تحريك للشعار مستوحى من فيديو شعار الجزيرة: قلم ضوئي يرسم الشعار من طرفه العلوي مع شرارات، ثم وميض وموجة صدمة، ثم يستقر الشعار بألوانه الأصلية، ثم تظهر كلمة **"قريباً"** من اليمين لليسار مع توهّج ولمعة ضوئية، مع مؤثرات صوتية مُصمَّمة بالكامل برمجياً (Riser، Whoosh، Impact، Shimmer، Chime، Reverb).

- الفيديو النهائي: `out/coming_soon.mp4` (‏1080×1920، 30fps، 7.5 ثانية، صوت AAC ستيريو 48kHz بمستوى ‎-14 LUFS)
- السكربت: `src/render.py`

## إعادة التوليد

```bash
pip install numpy pillow scipy   # ffmpeg مطلوب أيضاً
python3 src/render.py            # -> out/coming_soon.mp4
python3 src/render.py --preview  # صور معاينة كل نصف ثانية بدل الفيديو
```

التوقيتات (`T_DRAW0`, `T_HIT`, `T_TEXT0`…) في أعلى السكربت قابلة للتعديل.

الخط: Cairo (رخصة SIL OFL).
