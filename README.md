# من دِلّة القهوة إلى هوية مشروعك — موشن جرافيك One Shot

فيديو موشن جرافيك عمودي (1080×1920، مناسب للريلز وتيك توك وستوري) لمدة **53 ثانية**، مبني على هوية **مؤمن أيمن** البصرية: الشعار، الأزرق والبرتقالي، الخلفيات المتدرجة، وصورة المصمم.

الفيديو كله **لقطة واحدة متصلة بلا أي قطع**. كاميرا افتراضية واحدة تتحرك داخل مساحة تصميم كبيرة، وكل عنصر يطلع من العنصر اللي قبله.

## المسار البصري

| الوقت | المشهد | الحركة الأساسية |
|---|---|---|
| 0–6 ث | الهوك | حبّة بن بلقطة قريبة جدًا، تدخل حبات أخرى بمسارات حلزونية وتدور حولها، وتكبر الحبة الأساسية حتى تتحول دائرتها (Shape Morph) إلى فتحة الدلّة، ثم يرسم المحيط شكل الدلّة (Trim Paths). بعدها يظهر سؤال الهوك بـ Mask Reveal |
| 6–16 ث | مكونات القهوة | تمشي حبات البن على مسار حدود الدلّة، وتتجمع في وردة متوازنة («بُنّ أصيل»). تدخل حبات الهيل وتتفتح الحبة الوسطى وتتناثر بذورها ثم تنتظم في صف («هيل»). يرتفع خط من البذور ويتحول إلى لهب تحت الدلّة («نار هادئة»)، وتكتمل الدلّة: الصبّاب والمقبض والحلقات |
| 16–25 ث | من القهوة إلى الهوية | ينسكب خط من صبّاب الدلّة، والكاميرا تلحقه للأسفل حتى يستقيم ويصير خط تصميم. يتفرع الخط إلى Grid، وتتركب داخله وحدات المحتوى («محتوى واضح»)، ثم تتحول إلى ألوان الهوية وعيّنة الخط والشعار («هوية بصرية مميزة») مع ميلان خفيف للكاميرا يبيّن العمق |
| 25–36 ث | جودة التصاميم | تتقدم وحدة الشعار للأمام وتصير لوحة إعلانية، وبعدها تنقسم إلى ثلاث تطبيقات للهوية: بوست، كرت أعمال، ستوري. الأول ينزلق، والثاني يدور، والثالث يتوسع. بعدها تتوحد وتنربط بخطوط وتنكمش نحو المركز |
| 36–44 ث | ظهور المصمم | تتراجع التطبيقات للخلفية، ويرسم الإطار نفسه حول المركز. تنكشف صورة مؤمن بقناع دائري، ثم الاسم بمسح من اليمين لليسار، ثم الشعار في فتحة الإطار، ويكتمل الإطار مع «انطباعًا يليق فيه» |
| 44–53 ث | الدعوة للتفاعل | يصغر الاسم إلى بطاقة تعريف في الأعلى، وينطلق منها الخط ويرسم إطار كلمة «قهوة». أيقونة التعليق تمشي على المسار نفسه، والدلّة تدخل من طرف الكادر وتميل كأنها تصبّ. آخر ثانيتين ثابتتين تمامًا عشان تنقرا الدعوة |

## توقيت الفويس أوفر (Cue Sheet)

سجّل الصوت على هذه التوقيتات تقريبًا، ثم ادمجه بأمر `--audio` (التفاصيل تحت):

| من | إلى | النص |
|---|---|---|
| 0.6 | 4.6 | تدري وش علاقة دِلّة القهوة السعودية بهوية مشروعك؟ |
| 6.3 | 8.8 | مثل ما القهوة تحتاج **بُنّ أصيل** (الكلمة عند ≈7.8) |
| 9.0 | 11.2 | وهيل يضبط نكهتها (**هيل** عند ≈9.3) |
| 11.5 | 14.2 | ونار هادئة تبرز مذاقها… (**نار هادئة** عند ≈11.7) |
| 16.3 | 19.5 | مشروعك يحتاج **محتوى واضح** (≈18.3) |
| 20.0 | 22.8 | و**هوية بصرية مميزة**… (≈20.6) |
| 25.5 | 30.0 | **وتصاميم احترافية** (≈26.0) **تعكس قيمته** (≈28.0) |
| 36.3 | 43.5 | وأنا **مؤمن أيمن** (≈37.0)، أحوّل هالعناصر إلى هوية بصرية تخلي مشروعك يترك **انطباعًا يليق فيه** (≈42.2) |
| 44.3 | 50.0 | اكتب **قهوة** (≈45.0) بالتعليقات، وخلّنا نصنع لمشروعك **حضورًا ما يُنسى** (≈48.7) |
| 51.0 | 53.0 | ثبات كامل |

إذا جا التسجيل بإيقاع مختلف، تقدر تحرك أي حدث من أرقام التوقيت في `motion/src/film.js`. كل حركة مكتوبة كـ `p(t, بداية, نهاية, منحنى)`.

## التشغيل والمعاينة

```bash
cd motion
npm run preview          # افتح http://localhost:8080 — فيه زر تشغيل وشريط تقديم وتأخير (Space للتشغيل)
```

## إخراج الفيديو

```bash
cd motion
node render.mjs                         # output/coffee-identity.mp4 — 30fps
node render.mjs --fps 60 --out output/coffee-identity-60fps.mp4
node render.mjs --audio ../vo.wav       # دمج الفويس أوفر
node render.mjs --stills 5,20,47        # صور ثابتة للمراجعة
```

يحتاج Node 18 أو أحدث، و`ffmpeg`، و Playwright (Chromium).

## الهوية البصرية — كيف تعدّلها

كل شي موجود في `motion/src/theme.js`:

- **الألوان**: أزرق الشعار `#2F91D0` وبرتقالي المعيّن `#F9AE37` مأخوذين من ملف الشعار نفسه. أضفت درجة كحلية `#0D2B4A` (أغمق من الأزرق نفسه) للنصوص بس، عشان تكون واضحة على الخلفية الفاتحة، ودرجة سماوية فاتحة من الخلفية. ما في أي لون من خارج الهوية.
- **الشعار**: مفصول إلى طبقات شفافة (`assets/logo-m.png` و`assets/logo-diamond.png`) عشان يتحرك حرف M والمعيّن البرتقالي كل واحد لحاله. إذا عندك ملف SVG أو PNG شفاف أصلي، حطه مكانهم وتصير الجودة أعلى.
- **الخلفيات**: الخلفية المخططة شغالة طول الفيديو، وتتحول تدريجيًا للخلفية المحببة عند ظهور المصمم (بدون قطع).
- **صورة المصمم**: `assets/designer.jpg`.
- **الخط**: IBM Plex Sans Arabic (رخصة OFL) لأن ملفات الهوية ما فيها خط. إذا عندك خط معتمد، بدّل ملفات `assets/fonts` واسم الخط في `theme.js`.
- **النصوص**: كل الكلام اللي يظهر على الشاشة موجود في `copy`، ومنه السطر التعريفي «مصمم هويات بصرية · أكثر من 10 سنوات خبرة».

## هيكل المشروع

```
motion/
  index.html        مشغّل المعاينة + تحميل الخطوط والأصول
  src/theme.js      الهوية: ألوان، أصول، نصوص
  src/engine.js     منحنيات Bezier (مثل الـ Graph Editor)، Keyframes، Trim Paths
  src/film.js       اللقطة الواحدة كاملة — كل فريم دالة من الزمن t
  render.mjs        تصوير الفريمات وترميز MP4 (H.264)
  assets/           الشعار، الخلفيات، صورة المصمم، الخطوط
```
