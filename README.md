# شعار رام متحرك — "قريباً"

نسخة مطابقة لأسلوب ريفرنس الجزيرة على شعار **رام للشؤون العسكرية والأمنية**:

- كرت أزرق فوق خلفية بنفسجية غامقة، وخلفه شعار ضخم مموّه.
- الشعار أبيض متوهّج، مبني من الشعار الأصلي ومقسوم لطبقاته الحقيقية.
- **Trim Path**: كل طبقة تنرسم أولاً كستروك أبيض رفيع مع شرارات، ثم يلحقها الفيل بعد جزء من الثانية. الطبقات متتابعة بسرعة مع تداخل.
- **الكاميرا**: تبدأ قريبة من الكرت وتعمل Zoom In وهي تتبع الرسم، ثم عند اكتمال الشعار **وميض** + Zoom Out سريع مع Motion Blur.
- علامات التنصيص تظهر، ثم **"قريباً"** تُكتب من اليمين لليسار مع توهّج، ثم لمعة.

الصوت مُصمَّم برمجياً: Riser للوميض، Whoosh لكل طبقة مع Pan، رنّات لمعان، Impact + رنين عند الوميض، Whoosh للـ Zoom Out، نقرات للكتابة، Chime لكلمة "قريباً"، وReverb.

- الفيديو: `out/coming_soon.mp4` (‏1080×1920، 30fps، 7 ثوانٍ، AAC ستيريو 48kHz)
- السكربت: `src/render.py` — التوقيتات (`T_LAYERS`, `T_FLASH`, `T_ZOOM_OUT`, `T_SOON0`…) في أعلاه.

```bash
pip install numpy pillow scipy   # ffmpeg مطلوب أيضاً
python3 src/render.py            # -> out/coming_soon.mp4
python3 src/render.py --preview  # صور معاينة
```
