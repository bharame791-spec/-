# ما زلت خائفًا، ما زلت وحيدًا: تصميم الرواية

نفس نظام تصميم الرواية الأولى (`../book`)، بس بروح أبرد: ورق رمادي متل الرماد، فرشاة فحمية بدل الوردي، وضو كهرماني واحد هو الأمل.

- `manuscript.txt`: نص الرواية.
- `illustrate.py`: بيرسم الغلاف ومشهد لكل فصل (بيستعمل أدوات الرسم من `../book/illustrate.py`).
- `build.py`: بيركّب الكتاب. فيه الاقتباسات والجمل الخاصة ونص الغلاف الخلفي.
- `output/`: نسخة القراءة، وداخل الكتاب للمطبعة (A5)، والغلاف.

لإعادة البناء: `python3 illustrate.py` وبعدها `python3 build.py`.
