# هوية رام البصرية

دليل الهوية الكامل: `brand/guide/index.html`

| المجلد | المحتوى |
|---|---|
| `assets/` | الشعار والرمز: ملوّن، معكوس، أحادي كحلي، أحادي أبيض (PNG شفاف مستخرج من صورة الشعار) |
| `social-kit/backgrounds/` | 8 خلفيات متدرجة × 3 مقاسات (منشور 1080×1350، مربع 1080×1080، ستوري 1080×1920) |
| `social-kit/glass-backgrounds/` | 6 تراكيب زجاجية جاهزة 1080×1350 |
| `social-kit/glass-shapes/` | 7 أشكال زجاجية منفصلة: SVG قابل للتعديل + PNG شفاف، نسخة للخلفية الداكنة وأخرى للفاتحة |
| `social-kit/generator/` | سكربت التوليد: `node brand/social-kit/generator/render.js` |
| `tokens.css` | الألوان والتدرّجات ووصفة الزجاج كمتغيرات CSS للموقع |

ملاحظة: ملفات الشعار مستخرجة من صورة نقطية. للطباعة الكبيرة يُعتمد ملف الشعار الأصلي (AI / SVG / PDF) من المصمم.
