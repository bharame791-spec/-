# نموذج تسجيل مبادرة «ارتقاء» على Google Forms

السكربت `create-form.gs` ينشئ النموذج كاملًا في حسابك على جوجل، ومعه جدول Google Sheets تصل إليه الردود.

## خطوات التشغيل (مرة واحدة فقط)

1. افتح <https://script.google.com> وسجّل الدخول بحساب جوجل الخاص بالمركز.
2. اضغط **مشروع جديد (New project)**.
3. احذف المحتوى الموجود، والصق محتوى الملف `create-form.gs` كاملًا.
4. اضغط **حفظ** ثم اختر الدالة `createIrtiqaForm` واضغط **تشغيل (Run)**.
5. وافق على الصلاحيات المطلوبة (Forms و Sheets). إذا ظهرت لك رسالة "Google hasn't verified this app" اضغط
   **Advanced** ثم **Go to ... (unsafe)**، لأن السكربت سكربتك أنت.
6. افتح **سجل التنفيذ (Execution log)**، وستجد فيه:
   - **رابط التسجيل** المختصر (`forms.gle/...`) للمشاركة مع أولياء الأمور.
   - رابط تعديل النموذج.
   - رابط جدول الردود.

## محتوى النموذج

**أولًا: بيانات الطالب**
- الاسم الرباعي للطالب (إجباري)
- المرحلة الدراسية: ابتدائية / إعدادية (إجباري)
- الصف الدراسي (إجباري، وتظهر الصفوف حسب المرحلة: الأول إلى السادس للابتدائي، والسابع إلى التاسع للإعدادي)
- أيام الدوام في المدرسة: السبت - الاثنين - الأربعاء / الأحد - الثلاثاء - الخميس (إجباري)
- اسم المدرسة (إجباري)
- تاريخ الميلاد (اختياري)

**ثانيًا: بيانات ولي الأمر**
- اسم ولي الأمر (إجباري)
- رقم هاتف ولي الأمر (واتساب)، مع التحقق من أنه رقم صحيح (إجباري)
- صلة القرابة بالطالب: الأب / الأم / الأخ / الأخت / الجد / الجدة / أخرى (إجباري)
